## .NET API documentation

Contains descriptions of .NET types and members (summary, parameters and return value) taken from
[.NET API reference documentation](https://github.com/dotnet/dotnet-api-docs) by Microsoft and the .NET Foundation,
licensed under the [Creative Commons Attribution 4.0 International License (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
Changes: only the entries for the classes offered by the extension were kept, cross-references were converted to short
type names, C# keywords to their Visual Basic form, and remarks and examples were omitted.

When the Windows display language is not English and the .NET Framework IntelliSense files for that language are installed
on the computer, descriptions are read from those local files; they are not included in the extension.

The .NET type and member signatures are read from the metadata of the .NET Framework 2.0.
